# Changelog — post-RC2 enhancements (2026-11-12)

## Invoices, receipts & credit sales
- **Shop website** on invoices/receipts: when a website is set in System Settings → Business, it appears in the contact identity block (with address/phone/email).

# Changelog — release candidate 2 (2026-11-02)

## Fixed (bugs found during the pre-ship review)
- **Invoices, quotes, purchase orders, goods-received notes and repair sheets could not be printed at all**: the templates queried the system database, which has no sales tables ("Document unavailable"). They now read the business database.
- Document layouts used CSS Qt cannot render (flexbox) and double page margins; replaced with table layouts.

## New
- **Universal printing** (`printing.py`): any installed printer or Save-as-PDF; A3/A4/A5/A6/B5/Letter/Legal/Tabloid/Executive; 58/76/80 mm receipt rolls cut to the receipt length; custom width x height; orientation, margins, zoom, copies, black & white; preview; test page; saved per computer; compact receipt layout chosen automatically on rolls; optional automatic receipt after each POS sale.
- **Real-time Backups** replace "sync": back up within seconds of a change or every 5/15/30 min, hourly, 4-hourly, daily, weekly; verified ZIPs; toast after every backup, red retry notice on failure; status pill; history list; final backup on exit; optional background GitHub upload; GitHub token encrypted with Windows DPAPI.
- **VAT-inclusive pricing** option (sales, quotes, POS): total always equals the shelf price to the cent.
- Auto-lock after inactivity (default 10 min), crash handler + rotating log file (`%APPDATA%\NextGenERP\logs`).
- Test suite (`tests/`, 43 tests) and Windows packaging scripts (`packaging/`).

- **Per-business branding**: logo (any PNG/JPG/BMP/GIF/WEBP, auto-resized and stored inside that business's data, so every client has their own and it travels with backups), tagline, payment details (M-Pesa/bank) and a custom footer message on invoices and receipts. Set in System Settings → Business.

## Release candidate 2 additions
- **Business Pulse** dashboard card: today vs yesterday, daily goal ring, 14-day chart, selling streak, rotating insights (top seller, busiest hour, week-on-week, low stock, unpaid invoices), a once-a-day morning recap, and one-time celebrations for real milestones (goal reached, best day ever, streaks, sales and revenue milestones).
- **Shifts & Z-report**: opening float, cash count, expected vs counted variance, printable Z-report (roll or A4), optional "require an open shift before selling".
- **Report centre**: 10 reports with period picker, CSV export and printing.
- **POS**: hold/recall sales (F6/F7), shift gate.
- **Command palette** (Ctrl+K) and **screen lock** shortcut (Ctrl+L); responsive dashboard card.
- Dashboard no longer shows another business's brand name ("99 COMPUTERS" was hard-coded); catalogue tools only appear when a website feed is configured.
- Fixed: School profile's "Students & Enrolment" page crashed on open (a button name was shadowed by a function).
- Tests: 92 automated tests, including opening every page of all 14 business profiles.
